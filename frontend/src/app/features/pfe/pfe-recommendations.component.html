Comment ça marche ?

  1. Notre algorithme analyse votre profil (compétences + intérêts).
  2. Il vectorise vos données avec TF-IDF.
  3. Il calcule la similarité cosinus avec chaque sujet ouvert.
  4. Les sujets les plus pertinents sont classés par score.
